Cập nhật nhanh từ câu lệnh cURL (Khuyên Dùng)

Khi phiên đăng nhập WeSign hết hạn hoặc bạn muốn chuyển sang đợt hợp đồng khác, chỉ cần copy cURL từ trình duyệt và dán vào đây. Hệ thống sẽ tự động trích xuất Token, Cookie, Batch ID và Tenant ID.

Cách lấy cURL từ trình duyệt Chrome / Edge / Cốc Cốc:

1. Mở trang WeSign danh sách hợp đồng -> Nhấn phím F12 (hoặc chuột phải -> Kiểm tra / Inspect).

2. Chọn tab Network (Mạng) -> Lọc chữ batch-data (hoặc tải lại trang F5).

3. Chuột phải vào request batch-data -> chọn Copy -> chọn Copy as cURL (bash).

4. Dán vào ô bên dưới và bấm nút "Phân Tích & Cập Nhật".

Cấu Hình Agency Portal (Lấy SĐT & Mở Zalo Tự Động)

Hệ thống tự động dùng API của Agency Portal để tìm số điện thoại của NLĐ theo số CCCD và tạo link chat Zalo trực tiếp.

Khi cookie Agency Portal hết hạn, bạn chỉ cần:

1. Mở trang logistics.myagencyservice.vn -> Nhấn F12 -> Chọn tab Network (Mạng).

2. Lọc request tên ops/list hoặc bất kỳ request nào trên trang đó.

3. Chuột phải -> Copy -> Copy as cURL (bash) -> Dán vào bên dưới và bấm nút lưu.
